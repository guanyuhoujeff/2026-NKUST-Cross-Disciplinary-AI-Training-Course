## 🔌 第一件事：讓機器開始下載（現在就做）

下午的實作要用到一個 **1.2GB 的模型**。**現在按下去，它會在你聽課、做上午練習的時候慢慢拉完。**

> **上午的 Lab 1 完全用不到它** —— 所以下載跑到中午都沒關係，不會擋住你任何一步。

### ① 拿教材

```bash
git clone https://github.com/guanyuhoujeff/2026-NKUST-Cross-Disciplinary-AI-Training-Course.git
```

> 不熟 git 的：直接按這頁上方綠色的 **Code → Download ZIP**，解壓縮就好。

### ② 裝套件（在專案根目錄跑）

```bash
pip install -r requirements.txt
```

### ③ 裝 Ollama ＋ 開始拉模型（下午才用，現在先讓它跑）

到 **https://ollama.com/download** 下載安裝（**Windows 裝完要重開終端機**），然後：

```bash
ollama pull bge-m3
```

> **1.2GB，會跑一陣子——按下去就晾著，繼續聽課。** 中斷了重跑同一行會續傳。

### ④ 辦一把雲端 API key（下午生成要用）

到 **https://ollama.com/settings/keys** 註冊、建一把 key，**先貼在記事本存著**。下午的 Lab 2 會教怎麼用它。

> ⚠️ 一人一把自己的 key（額度是個人帳號的，各用各的不會互搶）。
> 🔒 **key 等於你帳號的鑰匙——不要貼到公開的地方、不要把填了 key 的 notebook 傳給別人。**

### ✅ 中午前確認這三樣

**Ollama 裝好** ／ `ollama list` **看得到 `bge-m3`** ／ **key 拿到手**。
（Lab 2 的 notebook 開頭有四格自我檢查，跑一格看一個燈。）

## 📚 課程 2：人工智慧與金融科技

主線是一句話：**從爬資料，一路做到用 AI 輔助投資決策。**

| Lab | 你會做出什麼 | 什麼時候 | 要用到什麼 |
|---|---|---|---|
| **[Lab 1 金融爬蟲](2_人工智慧與金融科技/Lab1_金融爬蟲/)** | 把證交所股價、財經新聞抓回來變成表格（`prices.csv`＋`news_raw.csv`） | 第 2 天上午 | 只要 Python 套件（**不用 API key、不用模型**，但要能連網） |
| **[Lab 2 pandas 財務資料](2_人工智慧與金融科技/Lab2_pandas財務資料/) ⭐** | 把髒股價洗乾淨（民國日期、千分位逗號）→ 做成特徵表 → **第一次 train/test 時序分割** | 第 2 天上午 | 只要 Python 套件（**幾乎全程離線**，只有一格要連網） |
| **[Lab 3 KNN 與決策樹](2_人工智慧與金融科技/Lab3_KNN與決策樹/) ⭐** | 用兩台分類器（KNN／決策樹）拿財務指標猜漲跌，再親手把它們調到過擬合，學會用「樣本外」誠實驗證、找甜蜜點 | 第 2 天下午 | 只要 Python 套件（sklearn，全程離線） |

> **Lab 1 → Lab 2 是接著的：** Lab 1 抓回來的髒資料，Lab 2 洗乾淨、做成模型能吃的特徵表。
> Lab 2 結尾產出的 `(X, y)` 特徵表，就是後面 KNN / 決策樹直接要吃的東西。

## 🛟 出事了怎麼辦

| 狀況 | 怎麼辦 |
|---|---|
| **模型下載很慢 / 拉不動** | 教室網路塞車。**找講師拷貝**（講師有備份），別在那邊乾等 |
| `KeyError: 'OLLAMA_API_KEY'` | 沒跑到貼 key 的那格 → 回 notebook 最上面「檢查」那格把 key 貼進引號中間，再從頭一格格跑 |
| `model not found` | 雲端模型名要帶 cloud tag（`gemma4:cloud`） |
| 連不上 `localhost:11434` | 本機 Ollama 沒跑起來 → 開一次 Ollama App，或下 `ollama serve` |
| **`faiss-cpu` 裝不起來**（Windows 常見） | 見 Lab 3 的 README，有 chromadb 替代方案 |
| **雲端不通 / 額度用完** | 每個 notebook 最後都有 **Backup 格**，改用本機模型跑完（品質降，但流程不斷） |
