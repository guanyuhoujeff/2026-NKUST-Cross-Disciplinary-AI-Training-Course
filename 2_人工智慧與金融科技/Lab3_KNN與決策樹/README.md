# Lab 3 五種模型，同一把誠實的尺

分成上下兩本。

**上半場**先用自己編的 100 家公司，把五種模型各跑一次，**每一種都把它的判斷畫成一張圖**——看清楚每種模型「怎麼畫線」。最後把資料切成兩份，一份藏起來當考卷，看誰是真的學會、誰只是把答案背下來。

**下半場**換上 8 檔真實的台灣股票，**同樣的動作再做一次**，看數字會變成什麼樣。

## 怎麼開始

```bash
pip install -r requirements.txt
jupyter notebook Lab3_KNN與決策樹_上_教學版.ipynb
```

或直接在 notebook 裡跑第一格的 `!pip install`。

## 內容

### 上半場（不需要網路）

| 段 | 內容 |
|---|---|
| **A** | 100 家自己編的公司：毛利率 × 負債比，兩個數字剛好畫成一張平面圖 |
| **B** | **KNN**——找最像的鄰居投票；把 `k` 轉到兩個極端看邊界怎麼變 |
| **C** | **決策樹**——問一連串問題；印得出規則、只會畫直角階梯、特徵重要性 |
| **D** | **隨機森林**——一群樹各投各的；用棵數遞增看破碎怎麼被平均掉 |
| **E** | **XGBoost**——一棵接一棵補前一棵的錯；跟森林比機制差在哪 |
| **F** ⭐ | **把考卷藏起來重考一次**——樣本內／樣本外／過擬合／欠擬合，四種模型一起考 |
| **G** | **KMeans**——沒有答案的時候怎麼辦；分群不是分類 |

### 下半場（**需要網路**）

| 段 | 內容 |
|---|---|
| **H** | 抓 8 檔真實台股、算 5 個技術指標；**時序切分**（時間序列不能隨機切）；四種模型重考 |
| **I** ⭐ | 掃 `k` → 掃 `max_depth` → **四種模型各挑一組不過擬合的設定** → 特徵重要性 |
| **J** | 收尾 ＋ 🥚 彩蛋：用最新一天預測「明天」，隔天回來對答案 |

## 環境需求

- Python 3.9+、scikit-learn、pandas、numpy、matplotlib、xgboost、yfinance
- **上半場完全不需要網路**（資料是程式生的，亂數種子固定 → 每個人數字一模一樣）
- **下半場整段需要網路**（連 Yahoo Finance 抓「到今天為止」的最新股價，不存快取）

## 數字說明

**上半場的數字固定**，每個人、每次跑都一樣。

**下半場的數字每次跑都不一樣**——因為每次都抓最新股價，筆數、分界日、挑到的設定、特徵重要性都會隨當天行情變動。**別對特定數字**，要看的是這個**結構**：樣本內 1.000 是陷阱、樣本外全部貼 5 成（≈擲銅板）。這個結論每次都成立。

環境實測版本：scikit-learn 1.6.1／pandas 2.2.3／numpy 1.26.4／matplotlib 3.10.0／xgboost 3.2.0／yfinance 1.3.0。

## Backup

| 狀況 | 怎麼辦 |
|---|---|
| `No module named 'sklearn'` / `'xgboost'` / `'yfinance'` | 跑第一格的 `!pip install`。**套件名是 `scikit-learn`，import 名是 `sklearn`**。裝不動改用 Colab。 |
| `pip` 裝了卻還是 import 不到 | 系統的 `pip` 可能指到別的 Python。改用 `python3 -m pip install ...`。 |
| **下半場連不上 Yahoo Finance** | 第 0 步的試抓那格會先告訴你。過幾分鐘再試（很多人同時抓可能被擋）。上半場不受影響。 |
| **數字跟教材不一樣** | 上半場不該不一樣（種子固定）；**下半場本來就會不一樣**（每次抓最新）。看結構別背數字。 |
| `max_depth=None` 寫成 `"None"` | `None` 是 Python 的「沒有值」，不要加引號。 |
| `export_text` 印出 `feature_0` | 忘了傳 `feature_names=feature_names`。 |
| 特徵重要性某個是 `0.0` | 不是壞掉——代表那個指標沒被拿來分岔。 |
| 圖上中文變成方框 | 電腦沒有中文字型。第 0 步那格已列了幾種備援字型，還是不行就先忽略，不影響數字。 |
| 想拿它去真的預測股票 | **別。** 樣本外才 5 成，跟擲銅板差不多。這裡學的是「怎麼誠實驗證模型」，不是「這個能拿去下單」。 |
