# 模組 4 遺傳演算法（GA）：用 PyGAD 挑投資組合 ＋ 揪過度最佳化

用現成的 GA 套件 **PyGAD**、即時抓真實的 **0050 成分股**股價，讓遺傳演算法自動找一組「權重」湊出夏普比（划算程度）最高的投資組合；再切樣本內／外，看漂亮的回測拿到「沒看過的未來」還剩幾分——這就是**過度最佳化**。數據路傳統 ML 三招（KNN → 決策樹 → GA）的收官。

## ⚠️ 今天的主角：過度最佳化

用真實 0050 成分股，**只示範最佳化與過度最佳化**。GA 挑的投組在回測漂亮、樣本外就縮水，本身就是「別信漂亮回測」的反例。最終決策要由人判斷（human-in-the-loop）。

## 🌐 需要網路（即時抓股價）

用 `yfinance` **即時抓** 0050 成分股近 4 年股價。**每次跑到的資料略不同 → 所有數字看趨勢、不對精確值。**

- 跑很慢或抓到 0 檔，多半是網路擋 yfinance → 重跑一次。
- **開課提醒：30 人同時抓可能被限流** → 講師可預先抓一份 CSV 發下去當備援（或分批抓）。

## 內容

- **A** 投資組合是什麼、夏普比、GA/PyGAD 直覺（黑盒子原理在投影片）
- **B** 即時抓 0050 成分股 → 算報酬 → PyGAD 找最佳投組（最近 60 天／季線）
- **C** 切樣本內／外（各 60 天）→ GA 只在樣本內找 → 樣本外考 → 過度最佳化
- **D** 收尾：「誠實衡量」貫穿全課、數據路三招收官
- **回家作業** 掃時間窗 1m/3m/6m/1y，看「窗越短崩越兇」

## 關鍵數字（某次即時抓的示意值，每次不同、看趨勢）

| | 樣本內 | 樣本外 | |
|---|---|---|---|
| GA 最佳（60 天窗） | 4.76 | **2.91** | 縮水＝過度最佳化 |
| 平均分配（不動腦） | 2.80 | **3.75** | 樣本外反而贏 GA |

掃窗作業（同一次）：1m 崩 −6.64、3m −1.94、6m −0.83、1y −1.01 → **窗越短崩越兇**。

> **保證主軸**：GA 樣本內漂亮 → 樣本外縮水（過度最佳化）。**彩蛋（不保證）**：常輸給平均分配，看當天資料。用 PyGAD `random_seed=83` 固定，同一份資料可重現。
