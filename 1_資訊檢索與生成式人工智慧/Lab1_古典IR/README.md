# Lab 1 古典 IR：親手做出一個最小搜尋引擎

課程 1「資訊檢索與生成式人工智慧」上午實作段（練 A～D）的 Jupyter Notebook 教材。
親手做出一個會「打分數、排名次」的最小搜尋引擎——它就是下午 Lab 3 RAG「檢索」那一半的原型。

> 語料聲明：`data/news/` 全部為**虛構、教學用**財經新聞（非真實行情，不含任何真實公司數字）。
